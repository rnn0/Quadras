# Arena Quadras

Projeto React + Vite para cadastro e reserva de quadras (com autenticação via Supabase).

## Requisitos

- Node.js (recomendado: LTS)
- npm

## Como rodar localmente

No diretório do projeto:

```bash
npm install
npm run dev
```

Depois abra no navegador a URL exibida no terminal (normalmente `http://localhost:5173`).

## Build (opcional)

```bash
npm run build
npm run preview
```
